# Compartilhar esta pasta

Esta cópia foi preparada sem banco de dados, pedidos reais, senha de produção, cookies ou credenciais de publicação. Os diretórios node_modules, dist, .wrangler e .git não foram incluídos.

Se você criar .dev.vars ou arquivos .env durante seus estudos, mantenha esses arquivos locais. O .gitignore já os ignora. O arquivo .dev.vars.example contém apenas nomes das variáveis.

O identificador em .openai/hosting.json se refere ao projeto Sites existente. Ele não é uma senha. Uma publicação precisa ser feita conscientemente no ambiente de hospedagem apropriado.
